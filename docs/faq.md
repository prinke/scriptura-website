# Frequently Asked Questions

---

## Is Scriptura free?
Yes. Scriptura is completely free to use.

---

## Does Scriptura work in DMs?
Yes, when installed as a user app.

---

## Can I use Scriptura in multiple servers?
Yes. You can install it in as many servers as you like.

---

## Why did my verse fail to load?
Common reasons include:
- Invalid verse reference
- Unsupported translation
- Temporary API issues

Try reformatting the reference or using the default translation.

---

## Can I request new features?
Absolutely. Open an issue or discussion in [the GitHub repository](https://github.com/prinketaru/scriptura).
