# Getting Started

Scriptura is a Discord bot that lets you quickly access Bible scripture directly inside Discord. You can install it in a server or use it as a user app anywhere user apps are supported.

This guide will help you get up and running in just a few minutes.

---

## Installing Scriptura

Scriptura can be used in two ways:

### Server Installation
- Install Scriptura into a Discord server
- Anyone with permission to use slash commands can access it
- Ideal for churches, study groups, and communities

### User App Installation
- Install Scriptura as a user app
- Use it in DMs and any server that allows user apps
- Personal and portable across Discord

Once installed, Scriptura is ready to use immediately — no setup required.

---

## Basic Usage

Scriptura uses Discord slash commands.

To see available commands:
- Type ``/`` in the message box
- Select Scriptura from the command list

The two core commands are:
- ``/verse`` — retrieve a specific Bible verse
- ``/daily-verse`` — receive a daily verse

Examples:
- ``/verse reference:John 3:16``
- ``/daily-verse``

By default, Scriptura uses the ESV translation unless you specify otherwise.

---

## Default Translation

If no translation is provided:
- Scriptura defaults to **ESV (English Standard Version)**

You can override this per command or save a preferred translation (see the [Translations page](/docs/translations)).

---

## What Scriptura Does Not Do

- No ads
- No tracking
- No message logging
- No storage of scripture requests

Scriptura is designed to be lightweight, private, and focused.
