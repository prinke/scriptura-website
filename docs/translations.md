# Translations

Scriptura supports multiple Bible translations.

---

## Default Translation

- `ESV` (English Standard Version)

If no translation is specified, ESV is always used.

---

## Specifying a Translation

You can specify a translation per command:

- `/verse John 1:1 NIV`
- `/daily-verse NLT`

---

## Saving a Preferred Translation

Scriptura allows users to store a preferred Bible translation.

When set:
- You no longer need to specify the translation
- All commands will default to your preference

This is the only user data Scriptura stores.

---

## Supported Translations

Supported translations depend on the data source used by Scriptura. Common examples include:

- `ESV`
- `NIV`
- `NLT`
- `CSB`
- `KJV`
- `NKJV`

If a translation is unavailable, Scriptura will notify you.
