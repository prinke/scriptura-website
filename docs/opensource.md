# Open Source

Scriptura is fully open source.

---

## Why Open Source?

Being open source means:
- Anyone can audit the code
- Transparency in how scripture is retrieved
- Community-driven improvement

---

## Contributing

You are welcome to:
- Report bugs
- Suggest features
- Submit pull requests
- Improve documentation

Check the repository for contribution guidelines.

---

## Self-Hosting

Advanced users may choose to:
- Fork Scriptura
- Run their own instance
- Customize features or translations

Refer to the [repository README](https://github.com/prinketaru/scriptura) for setup instructions.
