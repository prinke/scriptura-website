Use `/preferences` to save how Scriptura shows verses to you. Your settings follow you to every server and DM.

```
/preferences
```

The command has no options. It opens a **settings panel that only you can see**:

<PreferencesPanel />

## How the controls work

- **Translation dropdown:** pick your default translation.
- **Footnotes** and **Verse numbers:** tap to switch between **On** (green) and **Off** (grey).
- **Section headings** and **Line by line:** tap to cycle **Auto** (blue) → **On** (green) → **Off** (grey).
- **Reset display settings** (red): resets footnotes, verse numbers, headings and line by line to their defaults.
- Every change **saves immediately**. A confirmation line like *"✓ Footnotes set to on."* appears at the bottom.

<Aside type="note">
**Reset display settings** keeps your saved translation. To change it, pick another one from the dropdown.
</Aside>

The panel stops responding after **5 minutes without a click**. It then says *"This menu has expired. Run /preferences again to make more changes."*

## Defaults

| Setting | Default |
| --- | --- |
| Translation | ESV |
| Footnotes | Off |
| Headings | Auto |
| Verse numbers | On |
| Line by line | Auto |

## Which settings apply to which translations

Some settings only apply to certain translations. Each translation comes from a different scripture source, and not every source supports every setting.

| Setting | ESV | NKJV, KJV, NASB, NLT, ASV |
| --- | --- | --- |
| Footnotes | ✅ | — |
| Headings | ✅ (Auto = off) | — |
| Verse numbers | ✅ | ✅ |
| Line by line | Uses ESV's own formatting | ✅ (Auto = on for Psalms only) |

## Errors

If you see **Couldn’t load your preferences** or **Couldn’t save that change**, it's a temporary problem. Try again. Both messages are shown only to you.
