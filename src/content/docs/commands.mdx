Scriptura has five commands: `/verse`, `/audio`, `/daily-channel`, `/preferences` and `/ping`.

| Command | What it does | Who sees the reply | Where |
| --- | --- | --- | --- |
| [`/verse search`](#verse-search) | Get a passage or search for a phrase | Everyone in the channel | Anywhere |
| [`/verse daily`](#verse-daily) | Today's daily verse | Everyone in the channel | Anywhere |
| [`/audio play`](/audio/#audio-play) | Play the ESV audio Bible in your voice channel | Everyone in the channel | Servers |
| [`/audio stop`](/audio/#audio-stop) | Stop playback and leave the voice channel | Only you | Servers |
| [`/daily-channel set`](/daily-channel/#daily-channel-set) | Post the daily verse in a channel every day | Only you | Servers (admins) |
| [`/daily-channel view`](/daily-channel/#daily-channel-view) | Show the daily post schedule | Only you | Servers (admins) |
| [`/daily-channel disable`](/daily-channel/#daily-channel-disable) | Stop the daily posts | Only you | Servers (admins) |
| [`/preferences`](#preferences) | Open your settings panel | Only you | Anywhere |
| [`/ping`](#ping) | Check the bot's response time | Only you | Anywhere |

Error messages are always visible only to you.

## `/verse search`

Get a Bible passage by reference, or search the Bible for a word or phrase.

```
/verse search query:John 3:16
/verse search query:Psalm 23 translation:KJV
/verse search query:Romans 8:1-11 translation:NLT
/verse search query:1 Cor 13:4-7
/verse search query:love is patient
/verse search query:armor of God translation:NASB
```

| Option | Required | Description |
| --- | --- | --- |
| `query` | Yes | A Bible reference (e.g. `John 3:16`) or a phrase (e.g. `in love`) |
| `translation` | No | ESV, NKJV, KJV, NASB, NLT or ASV |

If your query looks like a reference, you get that passage. If it doesn't, Scriptura searches for it as a phrase. See [Writing references](/references/) for the formats it understands.

### Which translation is used

1. The `translation` you picked in the command, if any.
2. Otherwise, your saved translation from [`/preferences`](/preferences/).
3. Otherwise, **ESV**.

### Passage results

<DiscordMessage command="/verse search" embedTitle="Psalm 46:1" embedHref="https://www.biblegateway.com/passage/?search=Psalm+46%3A1&version=ESV" footer="English Standard Version (ESV)">
  <sup class="text-dc-muted">1</sup> God is our refuge and strength, a very present help in trouble.
</DiscordMessage>

- The **title** is the reference. Click it to open the passage on BibleGateway in the same translation.
- Verse numbers are shown as small superscript numbers. You can turn them off in [`/preferences`](/preferences/).
- With [footnotes](/preferences/) turned on (ESV only), the notes appear in their own **Footnotes** section below the passage. Their markers in the text are superscript numbers (¹, ²) that match the notes.
- The **footer** shows the translation's full name and code.
- Very long passages, such as some full chapters, are cut off at Discord's 4,096-character limit. Ask for a smaller range if that happens.

### Errors

If something goes wrong, Scriptura replies with a small red message only you can see. It has a short headline, sometimes a tip, and your query and translation in the footer.

<DiscordMessage command="/verse search" embedTitle="No results found" footer="“Hezekiah 3:1” · ESV" variant="error" ephemeral>
  Try a reference like “John 3:16” or a different phrase.
</DiscordMessage>

| Headline | When it appears | Tip shown |
| --- | --- | --- |
| **No results found** | The reference doesn't exist in that translation, or the phrase had no matches | "Try a reference like “John 3:16” or a different phrase." |
| **Something went wrong** | The scripture service didn't respond | "Couldn’t reach the ESV API / Bible Brain. Please try again in a moment." |
| **Couldn’t read that passage** | The verse was found but its text couldn't be read | "Try a different translation." |

## `/verse daily`

```
/verse daily
```

Shows today's daily verse. It has no options. The verse is shown in your saved translation (ESV if you haven't set one) with your display settings. It looks like a normal passage, with a **☀️ Verse of the Day** label above the reference.

Server admins can also have the daily verse posted automatically with [`/daily-channel`](/daily-channel/). Learn more on the [Daily verse](/daily-verse/) page.

## `/audio`

Listen to the ESV audio Bible in a voice channel. Join a voice channel, then run:

```
/audio play passage:Psalm 23
/audio stop
```

`/audio` only works in servers where Scriptura has been added. See [Audio Bible](/audio/) for the details.

## `/daily-channel`

For server admins: have Scriptura post the daily verse in a channel every day, at a time you choose.

```
/daily-channel set channel:#daily-verse time:8am timezone:America/New_York
/daily-channel view
/daily-channel disable
```

See [Daily verse posts](/daily-channel/) for every option.

## `/preferences`

```
/preferences
```

Opens a settings panel, visible only to you, where you can pick your translation and choose how verses are displayed. Changes save instantly and follow you to every server and DM. See [Preferences](/preferences/).

## `/ping`

```
/ping
```

<DiscordMessage command="/ping" embedTitle="🏓 Pong!" ephemeral>
  <p><span class="font-semibold text-white">Round trip:</span> 142 ms</p>
  <p><span class="font-semibold text-white">Heartbeat:</span> 38 ms</p>
</DiscordMessage>

Replies, only to you, with two numbers:

- **Round trip:** how long Scriptura took to respond to your command, in milliseconds.
- **Heartbeat:** Scriptura's connection latency to Discord, in milliseconds.

Use it to check that Scriptura is online and responding.
